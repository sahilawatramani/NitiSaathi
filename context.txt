## 1️⃣ SCHEME AGENT (Government Welfare Eligibility)

### What It Does:
Checks if gig workers are eligible for 7 Indian government welfare schemes and analyzes affordability.

### Knowledge Base (7 Schemes):
1. **e-Shram** - National database registration (free)
2. **PM-SYM** - Pension scheme (₹55-200/month → ₹3,000/month after 60)
3. **PMSBY** - Accident insurance (₹20/year → ₹2 lakh cover)
4. **PMJJBY** - Life insurance (₹436/year → ₹2 lakh cover)
5. **APY** - Atal Pension Yojana (age-based contributions)
6. **State Welfare Boards** - State-level programs
7. **Code on Social Security 2020** - Gig worker classification

### Core Features Implemented:

#### ✅ Gig Worker Classification
- **90-day rule**: Must work 90+ days on single platform OR 120+ days across multiple platforms
- Implements Code on Social Security 2020 definition
- Tracks days active and platform count

#### ✅ Eligibility Rules Engine (563 lines)
```python
# Ages boundaries:
e-Shram: 16-59 years
PM-SYM: 18-40 years (entry age)
PMSBY: 18-70 years
PMJJBY: 18-50 years
APY: 18-40 years

# Blocking conditions:
- EPFO/ESIC registered → NOT eligible
- Income tax payer → NOT eligible
- Must have bank account
- Must have Aadhaar linked
```

#### ✅ Affordability Analysis
- Reads user's monthly income
- Can integrate with Budget Agent state (income volatility, savings rate)
- Calculates if contribution is affordable
- Recommends waiting if income is unstable

#### ✅ Data Freshness Tracking
- Every scheme has `last_verified` date
- Checks staleness (default: 90 days)
- Flags outdated scheme information
- Critical for accurate eligibility

## 2️⃣ FRAUD GUARD (UPI Fraud Detection)

### What It Does:
Detects 9 fraud patterns specifically targeting gig workers and verifies RBI-registered lenders.

### Knowledge Base (9 Fraud Patterns):
1. **Fake KYC Calls** - "Your UPI will be blocked unless you verify"
2. **Fake QR Overlay** - Fraudulent QR placed over merchant codes
3. **Task-Based Job Scams** - "Send ₹500, earn ₹5,000 back"
4. **Fake Refund Requests** - "We sent money by mistake, send it back"
5. **New Counterparty Large Debit** - First-time large transaction
6. **Rapid Micro-Debits** - Multiple small debits quickly
7. **Large Atypical Debit** - Amount >>2x average
8. **Unusual Time Transaction** - Outside user's normal hours
9. **Suspicious Lender Contact** - Unregistered lender offering loans

### Core Features Implemented:

#### ✅ Hard Rules (CRITICAL)
```python
RULE 1: PIN/OTP Request Detection
- Regex patterns: "6-digit PIN", "4-digit OTP", etc.
- NEVER asks user for PIN/OTP
- If detected → CRITICAL alert immediately
- Zero tolerance - 100% fraud indicator

RULE 2: System Never Requests PIN/OTP
- Built into fraud detection
- Flags ANY message asking for PIN/OTP
```

#### ✅ Pattern Matching Engine (634 lines)
- Rule-based detection for 9 patterns
- Each pattern has:
  - Detection signals (what to look for)
  - Severity level (HIGH/MEDIUM/LOW)
  - User warning message
  - Examples
  - Mitigation advice

#### ✅ Anomaly Detection
```python
Features computed:
- Amount deviation (Z-score vs user average)
- New counterparty flag
- Transaction hour (unusual time)
- Velocity (transactions in 10 min window)
- Category mismatch
- Balance drop percentage
- Composite anomaly score
```

#### ✅ RBI Lender Verification
- Whitelist of RBI-registered banks, NBFCs
- Checks entity name against official list
- Flags unregistered lenders
- Detects suspicious URLs (.xyz, bit.ly, etc.)
- Extra validation for high-value loans

#### ✅ User History Analysis
Builds transaction profile:
- Average amounts (credit/debit separately)
- Known counterparties
- Category distribution
- Typical transaction hours
- Previous fraud incidents
